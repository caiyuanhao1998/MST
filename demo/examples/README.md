# Official SCI RGB examples

The visible examples are the 10 simulation-scene RGB images linked from the upstream MST README:

- Repository: https://github.com/caiyuanhao1998/MST
- Simulation RGB folder: https://drive.google.com/drive/folders/1EkJsOxYKgyehZdOgKUeY75dU19GHZgE-
- Real-scene RGB folder (5 additional images, not part of the visible examples): https://drive.google.com/drive/folders/1VTMgEbfX9MVpGo98XVVFKaANtQfgApAg

`simulation/manifest.json` records source file IDs, SHA256 hashes, and original sizes. PNG files are stored unchanged. Their resolutions vary because the repository provides them as figure RGBs. The application preserves aspect ratio and simulates measurements from these RGB inputs.
